## Selected projects

### [MLOps pipeline on SageMaker](https://github.com/shaun-friedman/mlops-sagemaker-keypoint-pipeline)
End-to-end pipeline for two production models: data cataloging and deduplication,
a feature store, training pipelines with quality gates, a model registry, endpoints
with data capture, and four monitors validated against both normal and
deliberately degraded traffic. Includes a benchmark built specifically to detect
whether the classifier was learning image source rather than image content.

`SageMaker Pipelines` `Model Monitor` `Feature Store` `PyTorch` `Glue/Athena`

### [Generative Interior Synthesis](https://github.com/shaun-friedman/Generative-Interior-Synthesis)
M.S. capstone. A two-stage pipeline that generates interior floorplans from a
building's exterior outline: a ResNet-50 U-Net predicts walls and doors, a custom
raster-to-graph extraction algorithm builds a room adjacency graph, and a graph
attention network labels each room.

`PyTorch Geometric` `Graph attention networks` `Semantic segmentation` `U-Net`

### [Breast ultrasound detection and segmentation](https://github.com/shaun-friedman/breast-ultrasound-segmentation)
Transfer learning with Mask R-CNN on the BUSI breast ultrasound dataset, evaluated
with COCO-style AP and AR for both bounding boxes and masks. My contribution to a
three-person graduate project. [Graduate coursework on a small public dataset; not
clinically validated.]

`Mask R-CNN` `Medical imaging` `Transfer learning` `COCO evaluation`
